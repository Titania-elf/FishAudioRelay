03 / CONNECT

接入 ST-iPhonie

Fish Audio 引擎

手机酒馆填这个地址；手机与本机需连同一个 Wi-Fi。

将这个 KEY 填入酒馆的 API Key 字段。

接入步骤
  1. 打开 ST-iPhonie 的引擎 → Fish Audio，API Key 填上面的中转专用 KEY 并保存。
  2. 填入上面的中转地址，点击「使用中转」或「保存中转」。将「中转接口格式」设为 OpenAI 格式（/v1/audio/speech）。
  3. 模型选上面的模型，音频格式选 MP3。点击「测试连接」；空请求返回 400 是正常的，不消耗生成额度。
  4. 在插件的角色设置中选择 Fish Audio，音色填上面的 32 位 ID；不同角色可以填各自的 Fish 音色 ID。
  5. 保持中转、Fish 标签页和连接窗口运行，再试听一句。套餐余额在本页查看；此接法不支持参考音频上传。

电脑上用 http://localhost:8000 或 http://127.0.0.1:8000 打开酒馆，填上面的「中转地址」；手机酒馆改填「手机酒馆中转地址」（该地址需用 Start-手机可用.bat 启动后才会出现）。
